## 1. Aim and transmitter architecture

Design a configurable single-antenna OFDM transmitter for an end-to-end wireless prototype. The frame carries a known synchronization preamble, a robust control header and a payload protected by CRC. Adaptive QPSK, 16-QAM and 64-QAM allow the next transmitted frame to trade bit rate for robustness according to the previous received SINR report.

Draw:

```text
Seeded payload bits → CRC-16 → frame/header → QAM mapper → 48 data bins
                                               + 4 pilot bins → 64-IFFT
                                               → 16-sample CP → preamble
                                               → power scaling → channel
```

## 2. Frame and parameter table

The payload is generated by MATLAB's `rng(3128 + frameId, 'twister')` and is therefore reproducible. Each frame stores its frame ID and original payload bits for *offline* BER validation. The receiver decodes without seeing these bits. CRC-16/CCITT-FALSE uses polynomial `0x1021`, initial register `0xFFFF`, MSB-first processing and no final XOR. Header CRC-8/ATM uses polynomial `0x07`, initial register zero. If the group instead uses registration-number-derived data, state the precise character-to-bit and framing method.

## 3. OFDM and adaptive modulation explanation

After Gray-coded symbol mapping, data is placed in 48 occupied data carriers and known pilots in four pilot carriers. DC and guards are left zero. The 64-point IFFT converts frequency bins to time samples; the final 16 samples are copied before each symbol as the cyclic prefix. The preamble consists of two identical known OFDM training symbols. The header is always QPSK so the receiver can discover payload mode and length.

The first frame uses QPSK. Subsequent mode choice uses **the previous frame's estimated SINR**: below 12 dB choose QPSK, 12–23 dB choose 16-QAM, above 23 dB choose 64-QAM. These cutoffs are placeholders until the group's receiver PER results establish suitable thresholds. Show the final tuned thresholds in the submitted version.

## 4. Calculations

EIRP = transmit power + transmit antenna gain − feeder loss = **15 + 2 − 0 = 17 dBm**. State that receiver gain and propagation loss belong in the link budget, and antenna gain is not directly applied again to the complex samples.

OFDM symbol duration = `(64 + 16) / 20,000,000 = 4 µs`. For 48 data carriers, the uncoded continuous-symbol bit rate is `48 × bits_per_carrier / 4 µs`: **24 Mbps QPSK, 48 Mbps 16-QAM and 72 Mbps 64-QAM**. These rates exclude preamble/header/CRC overhead and errors. For the current 96-byte QPSK example, the whole frame has 12 symbols = 48 µs, so its error-free payload airtime rate would be `768/48 µs = 16 Mbps`; this still excludes channel errors and retransmissions. Label these calculations carefully.

For the same 96-byte payload, 16-QAM and 64-QAM need 8 and 6 total OFDM symbols, so their zero-error frame payload rates are **24 and 32 Mbps**. Our 72 Mbps raw 64-QAM figure is uncoded and must not be called a standard Wi-Fi data rate. The exact rationale and remaining assignment gaps are in `LOKESH_VALUE_JUSTIFICATION_AND_PDF_AUDIT.md`.

The complete frame waveform is scaled so its average `|x[n]|²` equals `10^((15−30)/10) = 0.0316228 W` under a nominal complex-baseband convention. The receiver/channel model must use the same convention.
